# Attribution Guide

The project is intentionally public and reusable. Reuse should remain traceable to its source.

## Preferred credit

When redistributing or adapting educational material from this repository, use a credit reasonably equivalent to:

> **Computer Science Foundations — o0Zavira0o**
> Original repository: `https://github.com/o0Zavira0o/computer-science-foundations`
> Educational content licensed under **CC BY-SA 4.0**. Changes, if any, should be identified.

A link to this file or to the repository is an appropriate place to provide the fuller attribution details when inline credit would be impractical.

## What attribution is not

Attribution does not mean the original maintainer endorses a fork, course, product, translation, or adaptation. Reusers should describe their changes and their relationship to the original project accurately.

## Software

Software under `scripts/`, `tests/`, `.github/workflows/`, and `schemas/` is covered by GPL-3.0-or-later. Keep the applicable license notices when redistributing or modifying that software.

## Historical provenance

Git history records when material entered this repository and how it evolved. Commit history is useful provenance, but this file does not claim that Git history by itself resolves every possible legal dispute about authorship or copyright.
